# Practice Exercises Archive

This directory contains foundational daily practice exercises, algorithms implementations, and exploratory experiments covering:

- **Linear Regression**: Single & Multiple Linear Regression scripts and residual plots (`Linear-Regression.py`, `Multiple-Linear-Regression.py`).
- **Logistic Regression**: Binary and Multiple Logistic Regression models (`Logistic-Regression.py`, `Multiple-Logistic-Regression.py`).
- **Decision Trees**: Tree classification experiments (`Decision-Tree.py`).
- **Random Forest**: Multi-estimator decision boundaries and feature exploration (`Random_Forest.py`).
- **Support Vector Machines (SVM)**: Margin maximization and kernel classifications (`Support_Vector_Machine.py`).
- **Datasets**: Sample training datasets for salary, student grades, and housing prices.
